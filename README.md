# distributed-expense-tracker
A scalable expense-sharing application inspired by Splitwise, built using
Java, Spring Boot, React, Docker, and Kubernetes.

## Features
- User authentication
- Group expense management
- Balance calculation and settlement
- Containerized deployment
- Kubernetes-based scaling

## Tech Stack
- Frontend: React
- Backend: Java, Spring Boot
- Database: PostgreSQL
- DevOps: Docker, Kubernetes
